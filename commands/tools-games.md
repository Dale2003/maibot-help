# 工具与小游戏

除了舞萌成绩查询，Bot 还提供在线状态检查、随机选择、合格印章、人品统计与表情包，以及猜歌、Wordle、Handle、Maidle 和日麻练习等群聊功能。

## 常用工具

| 指令 | 作用 |
| --- | --- |
| `help` | 返回传统帮助图，并提示前往 help.dale2003.cn 查看完整帮助 |
| `ping` | 检查 Bot 是否在线与响应状态 |
| `dxpass` | 根据 QQ 生成当天固定的 DXPASS 图片 |
| `帮我选 A B C` | 从多个候选项中随机选择 |
| `宇航员猫娘` | 随机发送一张猫娘表情 |

`帮我选` 后没有直接给选项时，Bot 会等待约 60 秒，可以在下一条消息中补充候选项。

```text
帮我选 打舞萌 睡觉 吃饭
```

## 合格印章

把最多 6 个字做成对应风格的印章图片：

```text
/合格 收歌成功
/虹合格 今日上分
/不合格 还需努力
```

开头的 `/` 可以省略。

## 人品与日常互动

| 指令 | 说明 |
| --- | --- |
| `j` / `jrrp` / `今日人品` | 今日固定人品 |
| `本周人品` / `weekjrrp` | 本周平均人品 |
| `本月人品` / `monthjrrp` | 本月平均人品 |
| `总人品` / `alljrrp` | 历史总体人品 |
| `早安` / `晚安` | 群聊问候 |

戳一戳 Bot 时，它会随机回复文字或猫娘表情；在 Bot 具备群管理权限时，也可能触发短暂的玩笑禁言。

## 舞萌猜题

```text
猜歌曲
猜曲绘
猜谱面
猜BGA
```

只发送模式名会返回玩法说明；在后面加 `1` 或 `2` 开始对应模式。四种玩法都支持按版本、等级、流派和 DX / SD 筛题，例如：

```text
猜歌曲1
猜曲绘2
猜谱面2 白 lv13+ 东方
猜BGA1
```

使用筛选参数的对局不计分。排行榜可以只看某个模式：

```text
猜歌曲排行榜
猜曲绘排行榜
猜谱面排行榜
猜BGA排行榜
猜歌曲排行榜 2
```

游戏中直接发送答案，想结束时发送 `不玩了`。

### 倒放与加速猜歌

```text
倒放猜歌
倒放猜歌2 白 lv13+ 东方
加速猜歌
变速猜歌2
```

省略模式时使用 1。模式 1、2 分别从原音频取 6 秒、3 秒片段；倒放反转片段，加速模式以 1.25 倍速度播放并升调。支持原猜歌的筛选条件、答案和 `不玩了`，与其他猜题共用同群单局限制；超时会揭晓答案。新玩法不计入原排行榜。

## Wordle、Handle 与 Maidle

| 游戏 | 开始 | 辅助与结束 |
| --- | --- | --- |
| Wordle | `wordle`、`猜单词` | `提示`、`结束` |
| Handle 成语 | `handle`、`猜成语` | `成语提示`、`结束成语游戏` |
| Maidle | `maidle` | 按 Bot 提示直接回答 |

这些游戏会在当前会话保存进度；开始后再发送猜测内容即可。

Wordle 支持 3～12 位单词，默认 6 位、CET4 词典；Handle 支持严格成语检查：

```text
wordle -l 5 -d CET4
wordle --hint
wordle --stop
handle --strict
```

Wordle 与 Handle 连续 10 分钟没有游戏操作会自动结束，猜测后重新计时。

还有独立的单词匹配工具：用 `_` 表示未知字母，`#` 后填写需要排除的字母，建议使用小写：

```text
a__le
a__le#rst
```

匹配结果超过 50 个时需要缩小范围；无需先开始 Wordle。

## 表情包与图片工具

| 指令 | 作用 |
| --- | --- |
| `表情包制作` / `表情列表` | 查看当前可用的表情模板 |
| `表情搜索 关键词` | 搜索模板 |
| `表情详情 模板名` | 查看所需图片、文字、参数与预览 |
| `随机表情` | 随机选择模板，按模板要求提供图片或文字 |
| `图片操作` / `图片工具` | 查看图片处理指令 |
| `表情调用统计` | 查看表情使用统计 |
| `表情调用统计 --my` | 查看自己的统计 |

制作时使用“模板关键词 + 图片 / 文字 / @成员”，具体以 `表情详情` 返回的要求为准。可用模板会随资源和群内启用状态变化，以 Bot 返回的列表为准。

表情模板的群内开关为 `禁用表情 模板名`、`启用表情 模板名`，需要相应管理权限；全局开关由 Bot 管理员操作。

## 日麻练习

```text
日麻听牌
日麻算点
4番30符是多少点
```

- 听牌练习中使用 `答`、`答案` 或 `猜` 提交。
- 番符算点练习中使用 `算` 提交。
- `清一色听牌`、`日麻小游戏` 是听牌练习的别名；`番符点练习`、`日麻番符` 是算点练习的别名。
