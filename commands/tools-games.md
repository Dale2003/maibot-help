# 工具与小游戏

除了舞萌成绩查询，Bot 还提供在线状态检查、随机选择、合格印章、人品统计，以及猜歌、Wordle、Handle、Maidle 和日麻练习等群聊功能。

## 常用工具

| 指令 | 作用 |
| --- | --- |
| `help` | 返回传统帮助图 |
| `ping` | 检查 Bot 是否在线与响应状态 |
| `dxpass` | 根据 QQ 生成当天固定的 DXPASS 图片 |
| `帮我选 A B C` | 从多个候选项中随机选择 |
| `宇航员猫娘` | 随机发送一张猫娘表情 |

`帮我选` 后没有直接给选项时，Bot 会等待约 60 秒，可以在下一条消息中补充候选项。

```text
帮我选 打舞萌 睡觉 吃饭
```

## 合格印章

把最多 6 个字做成对应风格的印章图片：

```text
/合格 收歌成功
/虹合格 今日上分
/不合格 还需努力
```

开头的 `/` 可以省略。

## 人品与日常互动

| 指令 | 说明 |
| --- | --- |
| `j` / `jrrp` / `今日人品` | 今日固定人品 |
| `本周人品` / `weekjrrp` | 本周平均人品 |
| `本月人品` / `monthjrrp` | 本月平均人品 |
| `总人品` / `alljrrp` | 历史总体人品 |
| `年度人品` | 生成人品年度报告 |
| `早安` / `晚安` | 群聊问候 |

戳一戳 Bot 时，它会随机回复文字或猫娘表情；在 Bot 具备群管理权限时，也可能触发短暂的玩笑禁言。

## 舞萌猜题

```text
猜歌曲
猜曲绘
猜谱面
猜BGA
```

只发送模式名会返回玩法说明；按说明附加模式参数即可开始。排行榜写法：

```text
猜歌曲排行榜
猜曲绘排行榜
猜谱面排行榜
猜BGA排行榜
```

游戏中直接发送答案，想结束时发送 `不玩了`。

## Wordle、Handle 与 Maidle

| 游戏 | 开始 | 辅助与结束 |
| --- | --- | --- |
| Wordle | `wordle`、`猜单词` | `提示`、`结束` |
| Handle 成语 | `handle`、`猜成语` | `成语提示`、`结束成语游戏` |
| Maidle | `maidle` | 按 Bot 提示直接回答 |

这些游戏会在当前会话保存进度；开始后再发送猜测内容即可。

## 日麻练习

```text
日麻听牌
日麻算点
4番30符是多少点
```

- 听牌练习中使用 `答`、`答案` 或 `猜` 提交。
- 番符算点练习中使用 `算` 提交。
- `清一色听牌`、`日麻小游戏` 是听牌练习的别名；`番符点练习`、`日麻番符` 是算点练习的别名。

## 文案与图片互动

```text
ccb 舞萌玩家
恩情课文 宇航员猫娘
奶龙
我是奶龙
宇航员猫娘
```

`ccb` 也支持“搓搓背”“踩踩背”作为别名。
