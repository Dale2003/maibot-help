# 曲目与谱面

<img class="page-sticker" src="/images/meow-songs.png" alt="宇航员猫娘唱歌">

曲目查询主要读取 Bot 的曲库与别名库，不需要查分器授权；只有展示个人单曲成绩时才需要读取玩家数据。

## 查歌

| 指令 | 用法 | 示例 |
| --- | --- | --- |
| `查歌` | 曲名或别名的精确、包含匹配 | `查歌 潘多拉` |
| `模糊查歌` | ID、曲名或别名的模糊匹配 | `模糊查歌 潘朵拉` |
| `id` | 用 Song ID 直接查询 | `id 834`、`id#834` |
| `是什么歌` | 自然语言查询 | `潘多拉是什么歌`、`id834是啥歌` |

多结果时可在结尾添加 `-p 2`、`--page 2` 或 `第2页`，也可以在结果出现后直接发送页码。

查歌结果会绘制完整的曲目资料卡；除了曲名、ID、版本、定数等基础信息，还会带上与该曲目相关的称号（Title）介绍。

## 按条件查歌

```text
定数查歌 13.7
定数查歌 13.7 14.2 -p 2
bpm查歌 180
bpm查歌 160 200
曲师查歌 xi
谱师查歌 Jack
```

定数和 BPM 都支持单值或上下限。曲师与谱师按关键词匹配。

## minfo：单曲资料与个人成绩

`minfo` 支持曲名、别名和显式 ID：

```text
minfo 潘多拉
minfo id834
minfo 紫 潘多拉
minfo 白谱 id834
minfo id834 @群友
```

纯数字会优先按曲名或别名理解；要按 Song ID 查询，请写成 `id834`。指定颜色时会生成单张谱面的详细成绩图。

还支持查询自己的自然语言写法：

```text
我紫谱潘多拉多少分
我的白谱id834打了多少分
```

也可以用水鱼用户名查询指定难度，格式为 `<用户名>的<颜色>谱<曲目>多少分`：

```text
Dale的紫谱潘多拉多少分
```

这种显式用户名写法走水鱼；查询自己或艾特群友时，使用对应用户选择的查分器。

## 随机推荐

| 指令 | 说明 |
| --- | --- |
| `今天mai什么` | 随机推荐一首歌 |
| `今天mai什么推分` | 尝试结合成绩推荐推分曲目 |
| `今日mai` | 今日人品、宜忌与推荐曲 |
| `来个紫14+` | 随机一首指定难度和等级的歌 |
| `来个dx白14` | 限定 DX 类型、白谱与等级 |
| `来个标准红13` | 限定标准谱面 |

随机选歌格式为：`来个 [dx/sd/标准] [绿/黄/红/紫/白] <等级>`，发送时各部分可以连写。

## 别名查询与投稿

```text
查别名 潘多拉
歌曲别名 id834
潘多拉有什么别名
添加别名 834 新别名
```

投稿会进入审核列表，不会立刻覆盖现有别名。

## 分数线计算

发送 `分数线 帮助` 可查看 Bot 内说明。基本格式：

```text
分数线 紫799 100
分数线 紫id799 SSS
分数线 紫潘多拉 鸟加
```

成绩档位支持 A、AA、AAA、S、S+、SS、SS+、SSS/鸟、SSS+/鸟加。结果会给出可容忍的 TAP GREAT 数量，以及 BREAK 50 落的等价损失。

## 定数变化

```text
定数变化 紫 潘多拉
谱面定数变化 白 id834
dschange 红 潘多拉
```

颜色可省略；当同名曲目或谱面不唯一时，按 Bot 提示补充颜色或 ID。

历史定数图已纳入 `maimai でらっくす MAGiCAL`（1.70）的已收录数据。

### 历史版本定数表

在区服后写上版本，可以查询该版本的完整定数表，也可以再加等级或页码：

```text
日服FiNALE定数表
日服PRiSM+14+定数表
国服2024定数表
国服202414+定数表 第2页
```

版本范围与[按区服与版本模拟 B50](/commands/b50#按区服与版本模拟-b50)一致。使用对应历史版本的定数与等级标记，不用当前定数补齐缺失项。多页结果可以直接回复数字翻页。

历史定数表读取管理员预先生成的图片；提示缓存尚未构建或已失效时，需要联系管理员。`日服14+定数表` 等未写版本的指令仍查询当前日服表。

## 难度表与素材查询

发送 `14难度表` 或 `14+难度表` 查看“舞萌官方定数保护协会”难度表。

曲目 BGA 可按 Song ID 查询并上传到当前群文件：

```text
getmusicbga 834
getmusicmp4 834
```

两种写法等效。Bot 会先检查该完整 Song ID 是否已收录在曲库中，再查找对应视频；曲库未收录或视频资源缺失时不会提供 BGA。

群聊还支持音频和谱面预览视频：

```text
getmusicmp3 834
查看谱面 834
查看紫谱谱面 834
查看白谱谱面 834
```

`查看谱面` 默认查询紫谱，指定白谱时查询 Re:MASTER。文件会上传到当前群文件，谱面预览来源为落雪。上述媒体功能都依赖本地资源是否存在，未找到文件时会返回提示。

地图搜索、奖励路线、收藏品贴图与来源反查已整理到[地图与收藏品](/commands/maps)，包括 `查地图`、`mapid`、`收藏品来源`、`查询称号` 和各类 `…id` 指令。
