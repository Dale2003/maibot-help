# 地图与收藏品

查地图、查看奖励路线，以及按收藏品反查获取区域，都不需要查分器授权。结果会显示收藏品贴图、名称、ID、所属区域和所需距离，方便从想要的奖励找到对应地图。

## 搜索地图

```text
查地图 MAGiCAL
查地图 魔法
查地图 全部
查地图 全部 -p 2
```

支持地图名称、日文原名、版本关键词或地图 ID。只有一个匹配结果时，直接打开该地图的奖励路线；多个结果时，每页显示 6 张地图卡片，附带奖励数量、贴图预览和 `mapid` 查询指令。

`查询地图`、`查找地图`、`findmap` 是兼容写法。

## 地图奖励路线

使用搜索卡片上的地图 ID 查看路线：

```text
mapid700001
mapid700001 -p 2
mapid700001 -all
```

路线按距离排列，同一距离获得的奖励会放在一起，并显示与上一节点的距离差。收藏品卡片中可以查看原名、贴图、ID 和进一步查询的指令；称号会补充稀有度与达成条件。挑战曲节点表示到达该位置后开启挑战。

默认每页显示 8 个距离节点。在结尾添加 `-all`、`--all` 或 `长图` 可查看完整路线，无需手动翻页。

## 收藏品来源反查

格式为：`收藏品来源 <类型> <ID／名称／别名>`。

```text
收藏品来源 chara 700103
收藏品来源 旅行伙伴 初音未来
收藏品来源 chara Milk
收藏品来源 chara Milk -p 2
收藏品来源 chara Milk -all
收藏品来源 姓名框 700101
收藏品来源 music 834
```

每张来源卡片把区域名、地图指令、获取距离和对应收藏品放在同一个框内。同一收藏品有多个地图来源时会逐条展示；名称与别名也可以匹配多个收藏品或同角色的不同换装。

| 类型 | 可用写法 |
| --- | --- |
| 旅行伙伴 | `chara`、`character`、`旅行伙伴` |
| 搭档 | `partner`、`搭档` |
| 姓名框 | `plate`、`nameplate`、`姓名框`、`名牌` |
| 背景板 | `frame`、`背景板` |
| 头像 | `icon`、`头像` |
| 称号 | `title`、`称号` |
| 歌曲 | `music`、`歌曲`，包含解锁歌曲、任务曲和挑战曲 |
| 礼物 | `present`、`礼物` |

`收藏品反查`、`查收藏品`、`findsource` 是兼容写法。类型不能省略，因为不同类型的收藏品可能使用相同 ID。

### 名称与中英文别名

名称和别名支持包含匹配，英文不区分大小写。当前部分旅行伙伴、搭档已补充中文、英文或罗马字别名，例如：

```text
收藏品来源 chara 初音未来
收藏品来源 chara 日富美
收藏品来源 chara Milk
```

图片仍保留游戏原名，并显示已收录的别名。别名尚未覆盖所有收藏品；查询不到时，可以尝试原名的一部分，或用类型加 ID 精确查询。

### 分页与一次查看全部

收藏品来源默认每页 6 条。可以追加 `-p 2`、`-page 2` 或 `--page 2`，也可以收到分页结果后在同一会话中直接回复页码。

在结尾追加 `-all`、`--all` 或 `长图`，即可一次获取全部匹配来源；结果过长时会自动拆成多张图一起返回，无需逐页查询。完整结果模式不需要再写 `-p`。

| 查询 | 默认分页 | 查看全部 |
| --- | --- | --- |
| `查地图 全部` | 每页 6 张地图卡片 | 使用页码继续浏览，不支持 `-all` |
| `mapid700001` | 每页 8 个距离节点 | `mapid700001 -all` |
| `收藏品来源 chara Milk` | 每页 6 条来源 | `收藏品来源 chara Milk -all` |

::: info 地图资料的范围
来源反查只展示已收录的地图奖励，不涵盖所有活动、商店或其他获取方式。未查到来源不代表无法获取；地图是否仍开放，以游戏内为准。歌曲奖励仅展示 Bot 曲库中已收录的曲目。
:::

## 按 ID 查看素材

已有收藏品 ID 时，可以直接查询：

```text
charaid700103
partnerid123
plateid700101
frameid700501
iconid123
titleid123
musicid834
```

这些指令会返回对应图片或资料，并附上已收录的地图来源摘要；继续使用 `收藏品来源 <类型> <ID>` 可查看图文来源详情。

## 称号查询

按称号名称或达成条件搜索：

```text
查询称号 关键词
查询称号 关键词 -p 2
查询称号 ALL -c
```

`-c` 表示按达成条件查询。`称号查询`、`查找称号`、`findtitle` 是兼容写法；发送 `查询称号 -h` 可以查看参数说明。
