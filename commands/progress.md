# 进度与段位

<img class="page-sticker" src="/images/meow-progress.png" alt="思考中的宇航员猫娘">

这里集中介绍等级与版本牌完成进度、查段位曲、当前及历史段位，以及万花筒与棱镜塔成绩表。涉及个人成绩的查询通常需要先完成查分器授权。

## 等级进度

格式为：`<等级><目标>进度`。目标可使用成绩档位或 FC / FS 状态：

```text
13ap进度
14+sss+进度
14fc+进度
13+fdx进度
```

可以在后面填写页码、艾特群友或填写用户名。结果会把已完成、未完成和未游玩谱面分区展示。

## 版本牌进度与条件

```text
舞将进度
霸者进度
祭神进度 @群友
牌子条件
舞将完成表
```

常见版本字与目标组合均按当前 Bot 的牌子规则解析。只想了解条件时用 `牌子条件`，查看自己的完成情况用“进度”或“完成表”。

## 日服版本牌

在牌子指令前加 `日服`，按日服的版本划分查询。原有不带前缀的指令仍按原规则处理。

```text
日服华将完成表
日服祝神进度
日服丸极完成表 @群友
日服回舞舞进度
日服廻将完成表
日服牌子条件
```

目前支持 DX 初代至 CiRCLE PLUS，MAGiCAL 的牌子暂不支持：

| 日服版本 | 牌子字 | 日服版本 | 牌子字 |
| --- | --- | --- | --- |
| DX | 熊 | DX PLUS | 華 / 华 |
| Splash | 爽 | Splash PLUS | 煌 |
| UNiVERSE | 宙 | UNiVERSE PLUS | 星 |
| FESTiVAL | 祭 | FESTiVAL PLUS | 祝 |
| BUDDiES | 双 | BUDDiES PLUS | 宴 |
| PRiSM | 镜 | PRiSM PLUS | 彩 |
| CiRCLE | 丸 | CiRCLE PLUS | 回 / 廻 |

目标支持 `极 / 極`（FC）、`将`（SSS）、`神`（AP）和 `舞舞`（FDX），均统计该代 BASIC～MASTER；Re:MASTER 不加入这些单代牌子的条件。

- **成绩来源**：沿用当前选择的水鱼或落雪成绩，按日服原始版本归类。
- **进度**：只统计国服已收录的目标谱面；整代暂无可统计谱面时会提示查看完成表。
- **完成表**：沿用原完成表的绘图与成绩标记，国服未收录曲目照常画出，不额外标灰或添加特殊标识。
- **日服已删除曲目**：完成表会标注“日服已删除”，不计入达成条件；条件总图也会单列。

`日服牌子条件` 返回所有已支持日服版本的条件总图。个人进度与完成表会随查询读取成绩，无需经常发送更新指令；条件总图使用缓存，曲库和规则变化后会重新生成。

## 查段位曲

`查段位曲` 可以按曲名或别名查询一首歌曾出现过的段位，适合回看曲目的历代段位经历：

```text
查段位曲 Bad Apple
查段位曲 潘多拉
```

## 当前与历史段位

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `段位` / `段位表` / `段位成绩` | 当前国服段位 | `段位 真十段` |
| `<区服><版本>段位` | 指定区服与版本 | `日服pri+段位 里皆传` |
| `旧框段位表` | 旧框段位 | `旧框段位表 紫皆传` |
| `段位历史` | 按段位查询历史 | `段位历史 真十段` |
| `段位总表` | 按区服或版本生成总表 | `段位总表 国服2025` |

`段位历史`、`历史段位`、`段位查询` 是兼容写法。

日服 MAGiCAL（1.70）的固定段位已收录，可以这样查看：

```text
段位总表 日服MAGiCAL
段位总表 日服1.70
```

这里展示版本中收录的固定段位曲目；`随机段位` 是另一项成绩查询功能。

## 万花筒与棱镜塔

```text
青门解锁条件
万花筒紫门成绩表
棱镜塔紫谱成绩表
希望门成绩表
```

支持青、白、紫、黑、黄、赤各门，以及棱镜塔、表/里 Kaleidxscope 门和希望门。成绩表可添加绿谱、黄谱、红谱或紫谱限制。
