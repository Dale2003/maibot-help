# 进度与段位

<img class="page-sticker" src="/images/meow-progress.png" alt="思考中的宇航员猫娘">

这里集中介绍等级与版本牌完成进度、查段位曲、当前及历史段位，以及万花筒与棱镜塔成绩表。涉及个人成绩的查询通常需要先完成查分器授权。

## 等级进度

格式为：`<等级><目标>进度`。目标可使用成绩档位或 FC / FS 状态：

```text
13ap进度
14+sss+进度
14fc+进度
13+fdx进度
```

可以在后面填写页码、艾特群友或填写用户名。结果会把已完成、未完成和未游玩谱面分区展示。

## 版本牌进度与条件

```text
舞将进度
霸者进度
祭神进度 @群友
牌子条件
舞将完成表
```

常见版本字与目标组合均按当前 Bot 的牌子规则解析。只想了解条件时用 `牌子条件`，查看自己的完成情况用“进度”或“完成表”。

## 查段位曲

`查段位曲` 可以按曲名或别名查询一首歌曾出现过的段位，适合回看曲目的历代段位经历：

```text
查段位曲 Bad Apple
查段位曲 潘多拉
```

## 当前与历史段位

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `段位` / `段位表` / `段位成绩` | 当前国服段位 | `段位 真十段` |
| `<区服><版本>段位` | 指定区服与版本 | `日服pri+段位 里皆传` |
| `旧框段位表` | 旧框段位 | `旧框段位表 紫皆传` |
| `段位历史` | 按段位查询历史 | `段位历史 真十段` |
| `段位总表` | 按区服或版本生成总表 | `段位总表 国服2025` |

`段位历史`、`历史段位`、`段位查询` 是兼容写法。

日服 MAGiCAL（1.70）的固定段位已收录，可以这样查看：

```text
段位总表 日服MAGiCAL
段位总表 日服1.70
```

这里展示版本中收录的固定段位曲目；`随机段位` 是另一项成绩查询功能。

## 万花筒与棱镜塔

```text
青门解锁条件
万花筒紫门成绩表
棱镜塔紫谱成绩表
希望门成绩表
```

支持青、白、紫、黑、黄、赤各门，以及棱镜塔、表/里 Kaleidxscope 门和希望门。成绩表可添加绿谱、黄谱、红谱或紫谱限制。
