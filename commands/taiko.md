# 太鼓之达人

<img class="sticker-inline" src="/images/meow-taiko.png" alt="宇航员猫娘打太鼓">

发送 `taikohelp` 可以在群里获取太鼓功能帮助。下面整理了当前可用的完整写法。

## 查歌与谱面预览

```text
天竺2000是什么歌咚
1234是什么歌咚
查看太鼓谱面 松天竺2000
```

谱面难度前缀：梅/花 = 1，竹 = 2，松 = 3，鬼 = 4，里/里鬼 = 5。

## 鼓众广场绑定

| 指令 | 作用 |
| --- | --- |
| `绑定广场 <广场ID>` | 绑定自己的鼓众广场 ID |
| `解绑广场` | 删除绑定 |
| `taikoupdate` | 更新本地广场成绩 |
| `我的广场` / `我的小咚` | 查看自己的广场资料 |
| `tinfo <关键词>` | 查看单曲成绩信息 |

`tinfo @群友 天竺2000` 可以查询已经绑定广场的群友。

## B20 与 PC20

```text
taikob20
taikopc20
taikob20 @群友 -lv 8 -r 粉雅 -fc 金冠 -g 动漫 -s 神明收藏系列
```

- `taikob20`：生成 Rating B20 图片；别名 `taikort`、`taikorating`。
- `taikopc20`：按游玩次数排序，取前 20 的平均；别名 `taikopcrt`、`taikopcrating`。
- 常用筛选：`-lv` 星级、`-r` 段位、`-fc` 皇冠、`-g` 分类、`-s` 系列。

## 全分数列表与段位进度

```text
7星全分数列表
10星全分数列表 @群友
四段进度
三级进度 @群友
名人进度
```

全分数列表支持 1～10 星，并按鬼/里鬼定数分组。段位支持一级至五级、初段至十段、玄人、名人、超人和达人。

## 随机选歌

格式为 `来个<难度><星级>`：

```text
来个松8
来个鬼10
来个里10
```

如果已经绑定广场，结果会一并显示对应歌曲的个人成绩。

## 今日太鼓

```text
今日太鼓
太鼓卜卦
太鼓占卜 @群友
```

根据 QQ 生成当天固定的太鼓风格运势图，支持艾特群友。
