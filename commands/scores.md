# 成绩与分析

<img class="page-sticker" src="/images/meow-scores.png" alt="宇航员猫娘查看成绩">

这一组功能用于查看完整成绩、分析薄弱项和规划推分。默认查询自己；多数指令也支持艾特已经授权的群友。

## 常用分数列表

| 指令格式 | 说明 | 示例 |
| --- | --- | --- |
| `<等级>分数列表 [页码]` | 按等级查看 | `14+分数列表 2` |
| `<定数>分数列表 [页码]` | 按精确定数查看 | `13.7分数列表` |
| `<等级>dx分数列表 [页码]` | 按 DX 分展示 | `14+dx分数列表` |
| `<颜色><等级>分数列表 [页码]` | 指定谱面颜色 | `紫14分数列表` |
| `<流派>分数列表 [页码]` | 指定歌曲分类 | `东方分数列表` |

支持的颜色为绿、黄、红、紫、白；常见流派包括舞萌、音击、中二、V 家、流行、动漫、东方和其他游戏。

## 全分数列表

全分数列表会把指定等级的全部成绩生成在一张长图中，默认按完成率降序排列。支持查询自己，或在指令后艾特已授权的群友。

| 指令格式 | 说明 | 示例 |
| --- | --- | --- |
| `<等级>全分数列表` | 查看该等级的全部成绩 | `14+全分数列表` |
| `<等级>bpm全分数列表` | 在成绩卡中显示 BPM | `14+bpm全分数列表` |
| `<等级>bpm升序全分数列表` | 按 BPM 从低到高排列 | `14+bpm升序全分数列表` |
| `<等级>bpm降序全分数列表` | 按 BPM 从高到低排列 | `14+bpm降序全分数列表 @群友` |
| `<等级>拟合定数全分数列表` | 使用并显示拟合定数 | `14+拟合定数全分数列表` |

图片包含的成绩较多，生成时间可能比普通分页分数列表更长。

## AP、FC 与水平列表

直接把状态放在“分数列表”前：

```text
AP分数列表
FC+分数列表
牛逼分数列表
小牛逼分数列表
中牛逼分数列表
大牛逼分数列表
特大牛逼分数列表
超大牛逼分数列表
菜逼分数列表
大菜逼分数列表
越级分数列表
```

这些结果支持分页；收到多页结果后可直接发送页码。

## 高级筛选

发送 `分数列表 -h` 查看 Bot 内参数说明。常用格式：

```text
分数列表 -lv 14+ -d 紫 -fcl ap -p 2
分数列表 @群友 -l 13.8-14.2 -a 100-101 -r
```

参数与[新版 B50](/commands/b50#新版-b50-推荐)基本一致，另外支持：

- `-p`：页码。
- `-r`：按单曲 Rating 排序；默认按完成率排序。
- `-f`：使用拟合定数。
- `-i`：把成绩按理想下一档展示。

其余可用参数包括 `-s`、`-lv`、`-d`、`-fcl`、`-fsl`、`-t`、`-v`、`-g`、`-b`、`-a` 和 `-c`。

## 等级成绩分析

以下三种写法功能相同：

```text
13+成绩分析
13+分数分析
13+平均分数
```

可以在后面艾特已经授权的群友。结果会汇总指定等级的完成率、DX 分和成绩分布。

## 曲目与谱师分析

| 指令 | 说明 |
| --- | --- |
| `曲目分析` | 分析成绩中的曲目表现 |
| `谱师分析` | 按谱师汇总表现 |
| `鸟加曲目分析` | 只关注鸟加范围 |

## 含金量、含水量与底力

| 指令 | 说明 |
| --- | --- |
| `含金量分析` | 结合拟合定数分析高质量成绩 |
| `水分分析` / `含水量分析` | 查看相对偏高的成绩 |
| `鸟加含金量分析` | 只分析鸟加成绩 |
| `底力分析` | 综合底力分析 |
| `硬核rating` | 硬核 Rating 模型 |
| `杨氏rating` / `yrating` | 杨氏 Rating 模型 |

## 随机成绩与随机段位

```text
随机成绩
随机成绩 牛逼
随机成绩 丢人
随机段位 Master 上级
随机段位 Expert 超上级
```

随机段位的难度为 `Master` 或 `Expert`，级别为初级、中级、上级、超上级。

## 单曲 Rating 计算器

这组指令不读取玩家成绩：

```text
13.7的鸟加是多少分
13.7的100.2是多少分
13.7的多少是300分
```

前两种从定数和完成率计算单曲 Rating；第三种反推达到目标 Rating 所需的最低完成率。

## 成绩 PK

必须指定对手，推荐直接艾特群友：

```text
14+鸟加成绩pk @群友
13成绩对战 @群友
13dx分对战 @群友
```

可以省略等级或成绩档位，分别按完成率或 DX 分比较。

## 合并 B50

`合并b50` 会把你和另一名玩家的成绩合在一起：同一张谱面分别采用双方更高的完成率、DX 分和更好的 FC / FS 状态，再从合并结果中生成 B50。必须指定另一名玩家，可直接艾特群友或填写水鱼用户名。

```text
合并b50 @群友
合并b50 水鱼用户名
合并b50 @群友 -lv 14+ -d 紫
```

筛选参数与[新版 B50](/commands/b50#新版-b50-推荐)一致；发送 `合并b50 -h` 可以查看 Bot 内的完整参数说明。
