# 选曲与练习

这里的成绩查询使用当前选择的水鱼或落雪，不需要预先保存成绩快照。物量查歌和相似曲只读取曲库，不需要授权。各项均可加 `-h` 查看 Bot 内用法。

## 双人选曲

```text
双人选曲 @群友
双人选曲 @群友 -lv 14 -goal fc
双人选曲 @群友 14+ -min 98 -gap 1
```

只从双方都已游玩的共同谱面中推荐。默认红、紫、白谱，双方完成率至少 97%，分差不超过 2 个百分点；先按完成率接近程度排序，最多展示前 60 张谱面。

| 参数 | 作用 |
| --- | --- |
| `-lv 14` | 限定等级，也可以直接在指令后写 `14` |
| `-min 98` | 双方最低完成率 |
| `-gap 1` | 允许的最大完成率差，单位为百分点 |
| `-goal fc` | 排除双方都已完成的目标，保留仍有人需要补的项目 |
| `-p 2` | 查看下一页 |

目标支持 `sss`、`fc`、`fc+`、`ap`、`ap+`、`fs`、`fs+`、`fdx`、`fdx+`。FS 状态来自各自的个人最佳记录，不代表两人曾一起合奏。双方均需授权各自选择的查分器。

## 临时歌单成绩图

```text
歌单图 紫id834；白id799；红 Bad Apple
临时歌单图 紫id834；紫id799 @群友
```

每项都要填写颜色，用中文或英文分号分隔，最多 12 项，按输入顺序展示曲目和当前个人成绩。支持唯一曲名、别名和显式 ID；有多个匹配时，改用 `id834` 这种写法。重复的相同谱面只显示一次，歌单不会长期保存。

## 最接近的牌子

```text
最接近牌子 将
最接近牌子 神 -all
日服最接近牌子 极 @群友
```

目标支持 `极/極`、`将`、`神`、`舞舞`，默认将。按剩余谱面数从少到多排列，同数量时再比较剩余最高定数；同时列出剩余 14.0 及以上谱面的数量。未游玩谱面也计入剩余。

默认只列尚未完成的项目；加 `-all` 同时查看已完成项，`-p 2` 翻页。国服按原牌子规则统计，真将不列入排行。

日服按熊～回的原始版本划分，删除曲不计条件，国服未收录目标不计入排行；图片会另列完整条件数量。国服已收录范围完成，并不表示完整日服牌子已经达成。

## 全版本完成度

```text
版本完成度总览
全版本完成度 @群友
日服版本完成度总览
```

一张图汇总各版本 BASIC～MASTER 的 FC、SSS、AP、FDX 达成数与比例。国服共用条件的两字牌合并展示，不重复统计旧框总牌；日服各代分别展示，暂无国服目标的版本也会保留并标明情况。

这是当前成绩的覆盖情况，不是历史变化或游戏内奖励领取记录。

## 按物量查歌

```text
物量查歌 -lv 14 -slide 30-100 -touch 0 -break 0-10
物量查歌 -d 紫 -total 800-1200 -b 160-200 -sort total
物量查歌 -ds 13.6-14.2 -t SD -p 2
```

使用包含日服及历史曲的完整曲库，并补齐国服独有曲；同一歌曲优先使用完整曲库的定数、BPM、物量等数据。默认搜索红、紫、白谱，可用 `-d` 指定绿黄谱，最多展示前 500 张结果。历史曲不保证当前机台可玩。范围写法为 `下限-上限`，单值表示精确匹配。

| 参数 | 含义 |
| --- | --- |
| `-lv` / `-l` | 等级，例如 `14+` |
| `-ds` | 定数或定数范围，例如 `13.6-14.2` |
| `-d` | 绿、黄、红、紫、白或英文难度名 |
| `-t` | `SD` / `DX` |
| `-b` / `-bpm` | BPM 或范围 |
| `-total` | 总物量或范围 |
| `-break` | BREAK **数量**或范围 |
| `-tap` / `-hold` / `-slide` / `-touch` | 对应音符占总物量的**百分比**，0～100 |
| `-sort` | 按 `ds`、`total`、`break`、`slide`、`touch`、`bpm` 降序，默认定数 |
| `-p` | 页码 |

例如 `-slide 30-100` 表示 SLIDE 占比至少 30%，不是至少 30 个 SLIDE。旧标准谱的 TOUCH 数量按 0 处理。

## 相似曲推荐

```text
相似曲推荐 紫id834
相似曲推荐 紫 潘多拉 -ds 13.5-14.8
相似曲推荐 白id799 -t DX -p 2
相似曲推荐 紫id834 -d 红 -lv 13+
```

一次指定一张参考谱面，默认跨颜色、跨等级推荐其他歌曲，绿黄红紫白均参与。输入的颜色只用于指定参考谱面；需要限制候选颜色、等级或定数时，分别使用 `-d`、`-lv`、`-ds`，也可用物量查歌的其他筛选参数，最多展示前 60 张。

参考谱面和候选不限国服，使用包含日服及历史曲的完整曲库，并补齐国服独有曲。同一歌曲的定数、BPM 和音符资料优先使用完整曲库数据，所以可能与当前国服数据不同。可直接输入日服独有曲的曲名、已收录别名或 `id`。缺少有效定数、物量的谱面及宴谱不参与计算；基础兜底还需要有效BPM。历史曲不保证当前机台可玩。

优先使用**谱面文件分析**，同时比较两方面：

- **配置结构**：节奏间隔、键位位移、连续键型、双押、星轨形状及等待/持续时间、TOUCH区域、HOLD时长、滑动或HOLD期间的其他击打等。
- **实际强度**：按谱面变速表换算真实秒数，比较平均击打密度、短时爆发、4秒持续峰值、2秒窗口密度分布和空拍比例，并结合定数、BPM与总物量。物理击打和判定物量分开统计。

排序使用结构、真实强度、定数、BPM、总物量的综合距离。定数差越大，惩罚增长越快；仍允许跨颜色和跨等级推荐，也支持显式筛选较低难度。粗排阶段就考虑这些因素，局部比较同时检查双方代表片段，避免仅凭一段相似配置判断整首相似。权重是工程设定，未通过玩家相似度标注训练。

图片展示相近配置、定数差、BPM/总物量、每秒击打均值及1秒峰值，成对数值按“本曲/参考”排列。交替、相邻键扫动等是规则识别的候选，不代表唯一手法。曲绘缺失时会先尝试对应标准谱或DX谱的曲绘。

**缺谱面文件时自动兜底**：参考谱面缺文件时，全榜使用原算法；候选缺文件时，优先显示谱面分析推荐，最多预留6个基础兜底位置，结构结果不足时用基础结果补齐。图中以“基础兜底”区分。文件与当前曲库的音符统计不一致时也会兜底。

基础兜底仍按 `0.45 × 定数差 + 0.25 × 音符占比差 + 0.20 × BPM 差 + 0.10 × 谱师差` 排序。综合距离和基础距离各自越小越接近，**不直接互相比大小，也不是相似度百分比**。

该功能不会推荐参考歌曲的其他难度。结构相近仍需结合实际游玩判断，不能等同于难度相同或练习效果相同。

倒放、加速猜歌的玩法见[工具与小游戏](/commands/tools-games)。
