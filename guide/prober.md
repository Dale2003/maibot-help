# 查分器与授权

宇航员猫娘支持水鱼和落雪两种查分器。每位用户可以单独选择自己的数据源，成绩类功能会优先读取当前选择的查分器。

## 查看或切换查分器

| 指令 | 作用 |
| --- | --- |
| `查分器` | 查看当前查分器和落雪绑定状态 |
| `查分器 水鱼` | 切换到水鱼 |
| `查分器 落雪` | 切换到落雪；未绑定时会开始授权 |
| `prober` | `查分器` 的英文别名 |

Bot 默认使用水鱼。如果切换到落雪但授权失效，成绩查询会提示重新绑定。

## 水鱼 OAuth

发送：

```text
dfbind
```

Bot 会返回一次性授权链接。打开链接，确认页面上的 QQ 身份，再登录水鱼并同意授权。完成后无需把授权码发回群里。

::: warning
授权链接包含一次性状态，不要转发给其他人。需要撤销时，请使用 Bot 回复中提供的水鱼应用授权管理页面。
:::

## 落雪 OAuth

发送下面任意一个指令开始授权：

```text
lxbind
落雪绑定
查分器 落雪
```

如果 Bot 已配置自动回调，网页授权完成后会直接切换到落雪。如果网页显示一次性授权码，请在 10 分钟内私聊 Bot：

```text
lxauth 一次性授权码
```

授权码只允许私聊提交，不要发在群里。解除本地绑定可发送：

```text
lxunbind
```

这会删除 Bot 保存的落雪授权并切回水鱼；如需彻底撤销，还需要在落雪的应用授权管理中取消授权。

## 下载自己的查分器数据

在群聊发送：

```text
下载查分器数据
```

兼容别名：`下载水鱼数据`、`下载成绩数据`。Bot 会读取当前选择的查分器，并把完整成绩以 JSON 群文件上传。

只有 Bot 管理员可以通过艾特导出其他用户的数据：

```text
下载查分器数据 @群友
```

普通成员只能下载自己的数据。目标用户也必须已经授权其当前选择的查分器。

## 哪些功能会读取查分器

常见的 B50、分数列表、进度、成绩分析、随机成绩、推分建议、PK 与单曲个人成绩都会读取玩家成绩。查歌、定数表、分数线等纯曲库功能通常不需要授权。
