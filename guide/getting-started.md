# 快速开始

<img class="sticker-inline" src="/images/meow-guide.png" alt="宇航员猫娘查看文档">

宇航员猫娘是面向 QQ 群聊的舞萌 DX 与音游工具 Bot。核心功能包括成绩查询、B50、曲目资料、完成进度与段位信息，也提供太鼓查询和一些群聊小游戏。

## 指令怎么发送

大多数指令直接发送纯文本即可：

```text
b50
14+分数列表
查歌 潘多拉
今天mai什么
```

除特别注明外，不需要在开头添加 `/`，也不用先艾特 Bot。指令中的英文大小写是否兼容，以各页表格中的写法为准。

## 查询自己、群友或用户名

查询目标分为以下几种写法：

| 目标 | 写法 | 示例 |
| --- | --- | --- |
| 自己 | 只发送指令 | `b50` |
| 群友 | 指令后艾特一人 | `b50 @群友` |
| 水鱼用户名 | 标准 B50 后填写用户名 | `b50 Dale` |

每次只指定一个目标。标准 `b50` 可以用水鱼用户名；分数列表、分析、进度等需要完整成绩的功能，应查询自己或艾特已经授权的群友。带复杂参数的指令可这样写：

```text
新b50 -lv 14+ -d 紫
分数列表 -l 14+ -fcl ap -p 2
```

::: tip 数据范围
B50、分数列表与随机成绩只统计常规曲目记录；特殊曲目不会混入这些结果。
:::

## 先完成查分器授权

第一次查询成绩时，建议先发送：

```text
dfbind
```

打开返回的水鱼授权链接并同意授权。Bot 默认使用水鱼；如果你希望使用落雪，请查看[查分器与授权](/guide/prober)。

## 分页怎么操作

查歌等返回多页结果的功能支持两种方式：

- 在原指令后写 `-p 2` 或 `第2页`，例如 `查歌 天 -p 2`。
- 收到结果后，在约 5 分钟内直接发送页码，例如 `2`。

分数列表也可直接在命令中写页码，例如 `14+分数列表 2`；高级筛选使用 `-p 2`。

地图奖励路线和收藏品来源还支持一次查看全部：`mapid700001 -all`、`收藏品来源 chara Milk -all`。收藏品来源过长时会自动拆成多张图返回。`查地图` 的搜索列表仍使用分页，详见[地图与收藏品](/commands/maps)。

## 没有响应时

先按下面顺序检查：

1. 确认指令中间的空格、等级和符号与示例一致。
2. 成绩功能确认已经授权当前选择的查分器。
3. 图片生成较慢时不要连续重复发送；部分重型指令有短暂冷却。
4. 输入 `查分器` 检查当前数据源和落雪绑定状态。
5. 仍有问题时带上指令和报错截图到[支持作者](/support)页面列出的群反馈。
